Lock Back - standalone / نسخة مستقلة (no Node.js needed / لا تحتاج Node.js)

START / التشغيل
  Windows: double-click LockBack.exe   (if Firewall asks: Allow on Private networks)
  Mac:     double-click LockBack       (first time: right-click > Open)
The admin board opens by itself. Players join with the links shown in the black window (plain http, no browser warning).
تفتح لوحة المشرف تلقائياً، واللاعبون يدخلون من الروابط الظاهرة في النافذة السوداء (http عادي بدون تحذير).

Player numbers and printed coins are the same on every computer, and Reset never changes them.
أرقام اللاعبين والعملات ثابتة على كل الأجهزة، وزر Reset لا يغيّرها.
Extract the zip first, then run. A "data" folder appears next to the program (saved numbers, coins); keep it there.
فك الضغط أولاً ثم شغّل. يظهر فولدر "data" بجانب البرنامج (الأرقام والعملات)، اتركه مكانه.
